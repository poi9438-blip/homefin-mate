# 소득 암호화 (TC-ENC)

대상: `EncryptionUtil` — AES-256-GCM. 저장 형식은 `Base64(IV 12바이트 + 암호문 + 인증 태그 16바이트)`이고, 키는 `.env`의 `ENCRYPTION_KEY`입니다.

암호화 방식 변경이나 기존 암호문 일괄 변환은 이 테스트의 범위가 아닙니다.
