# 대출 계산 · DSR (TC-LOAN)

대상: `LoanService`, `LoanController` (`POST /api/loan/calculate`, `POST /api/loan/dsr`, `GET /api/loan/history`)

**현재 구현 (요구사항과 구분)**

- **월 상환액:** 원리금균등 공식 `M = P·r / (1 − (1+r)^−n)`
  - `r = 연이율 / 1200`, 소수 10자리에서 반올림합니다.
  - 월 상환액은 원 단위 소수 2자리입니다.
- **총상환액·총이자:** 총상환액 = M × n, 총이자 = 총상환액 − P
- **DSR:** 월 상환액 ÷ 월 소득, 소수 4자리입니다.
  - 0.43 이하이면 ACCEPTABLE입니다.
  - **기존 부채는 포함하지 않습니다**(#8, 우선 처리 J2 예정). 그래서 기존 부채를 반영한 결과는 테스트의 기대 결과로 쓰지 않습니다.
- **저장 범위:** `interest_rate`와 `dsr` 컬럼이 `DECIMAL(5,4)`라 9.9999까지만 저장됩니다.
