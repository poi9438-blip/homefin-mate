# 화면 공통 (TC-WEB)

대상: `frontend/src/utils/auth.js`(로그인 만료 시각 저장·확인), `frontend/src/api/axiosInstance.js`(XSRF 헤더, traceId, 401 처리), `frontend/src/hooks`(테마·큰 글씨), 대시보드·리포트·관리자 화면. 실행은 Vitest + jsdom입니다.

화면 테스트는 API를 가짜로 바꾸고 차트는 빈 컴포넌트로 대체해, 화면에 보이는 글자와 API 호출을 확인합니다. 기존 TC-WEB-301(만료 토큰)·302(traceId)는 TC-WEB-216·217로 대체했습니다. TC-WEB-202(깨진 사용자 정보 JSON)는 사용자 정보를 저장하지 않게 되어(#12) 폐기했습니다.

- **시각 표시 (#91):** 서버가 시각에 시간대를 붙여 보내므로(`2026-10-25T12:13:04Z`) 화면은 `new Date()`로 읽어 브라우저 시간대로 표시합니다.
- **로그인 상태 (#77, #78):** 토큰은 HttpOnly 쿠키라 화면이 읽을 수 없습니다. 로그인 응답의 `expiresAt`만 `hfm_session_expires_at`에 저장하고, 지났으면 서버에 묻기 전에 로그인 화면으로 보냅니다. 최종 판단은 서버(401이면 인터셉터가 정리)가 합니다.
