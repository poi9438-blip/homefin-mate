# 정책 추천 (TC-POL)

대상: `PolicyService` (`POST /api/policy/recommend`, 로그인 불필요)

**현재 구현 (J1, 2026-10-16):** 한국 주택구입 정책대출 2개의 자격 조건을 하나씩 판정합니다. 점수로 순위를 매기지 않습니다.

| 상품                | 운영 기관        | 공식 출처 (2026-10-16 확인)                                                           |
| ------------------- | ---------------- | ------------------------------------------------------------------------------------- |
| 내집마련 디딤돌대출 | 주택도시기금     | https://nhuf.molit.go.kr/FP/FP05/FP0503/FP05030101.jsp                                |
| 보금자리론          | 한국주택금융공사 | https://www.hf.go.kr/ko/sub01/sub01_01_01.do (금리: sub01_01_04.do, 2026년 10월 공시) |

- **판정할 조건:** 연소득(월 소득 × 12, 본인 기준), 주택 보유, 주택 가격, 대출 금액(상품 한도와 주택 가격 × LTV 중 작은 값), DTI 60%(앱의 DSR로 대신 확인)
- **조건별 결과:** 충족 / 미충족 / 확인 필요
  - 입력이 없으면 확인 필요입니다.
  - 가구 조건(생애최초·신혼·자녀 수)을 모르면 가장 낮은 기준과 가장 높은 기준 사이를 확인 필요로 봅니다.
- **상품 종합 판정:** 미충족이 하나라도 있으면 미충족, 확인 필요가 있으면 확인 필요, 모두 충족이면 충족입니다.
- **판정하지 않는 조건:** 면적, 자산, 신용, 세대주, 규제지역은 판정하지 않고 `additionalChecks`로 안내합니다.
- **기준이 바뀌면:** `PolicyService` 상수, 이 표, `PolicyServiceTest`를 함께 고칩니다.
- **확인 필요:** 보금자리론의 "다자녀 가구"는 상품안내 페이지에 인원 정의가 없습니다. 금리안내 페이지 우대금리 표(다자녀가구 2자녀 / 3자녀 이상)를 근거로 **자녀 2명 이상**으로 처리했습니다 (공식 정의 아님, 고객센터 1688-8114 확인 필요). 소득 기준(1억 원)과 한도(4억 원)에 영향을 줍니다.
