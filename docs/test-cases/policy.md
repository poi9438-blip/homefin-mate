# 정책 추천 (TC-POL)

대상: `PolicyService` (`POST /api/policy/recommend`, 로그인 불필요)

**현재 구현 (J1 2026-10-16, ⑨ 2026-10-26 신생아 특례 추가):** 한국 주택구입 정책대출 3개의 자격 조건을 하나씩 판정합니다. 점수로 순위를 매기지 않습니다.

| 상품                   | 운영 기관        | 공식 출처 (2026-10-26 확인)                                                           |
| ---------------------- | ---------------- | ------------------------------------------------------------------------------------- |
| 내집마련 디딤돌대출    | 주택도시기금     | https://nhuf.molit.go.kr/FP/FP05/FP0503/FP05030101.jsp                                |
| 신생아 특례 디딤돌대출 | 주택도시기금     | https://nhuf.molit.go.kr/FP/FP05/FP0503/FP05030801.jsp                                |
| 보금자리론             | 한국주택금융공사 | https://www.hf.go.kr/ko/sub01/sub01_01_01.do (금리: sub01_01_04.do, 2026년 10월 공시) |

- **판정할 조건:** 연소득(부부합산 연소득, 없으면 월 소득 × 12 본인 기준), 주택 보유, 주택 가격, 대출 금액(상품 한도와 주택 가격 × LTV 중 작은 값), DTI 60%(대출 계산의 DTI = (신규 대출 월 상환액 + 기존 대출 월 이자) ÷ 월 소득)
- **조건별 결과:** 충족 / 미충족 / 확인 필요
  - 입력이 없으면 확인 필요입니다.
  - 가구 조건(생애최초·신혼·자녀 수)을 모르면 가장 낮은 기준과 가장 높은 기준 사이를 확인 필요로 봅니다.
- **필수 입력 (대출 화면·정책 화면, 통합 분석 API):** 월 소득, 주택 가격, 부부합산 연소득, 생애최초, 신혼, 자녀 수는 필수입니다. 비우면 조건을 판정할 수 없어 추천이 나오지 않기 때문에 입력 단계에서 막습니다.
  - 신생아 특례용 "2년 안 출산·입양"과 "맞벌이"는 화면에서는 필수, API에서는 선택입니다(없으면 그 조건만 확인 필요). 기존 API 호출(k6 등)이 깨지지 않게 하기 위해서입니다.
- **상품 종합 판정:** 미충족이 하나라도 있으면 미충족, 확인 필요가 있으면 확인 필요, 모두 충족이면 충족입니다.
- **피드백:** 미충족이거나 확인 필요인 조건마다 `hint`로 "이렇게 하면 가능"을 알려 줍니다. 미충족이면 기준값(예: 대출 금액 2.1억 원 이하), 가구 조건 때문이면 해당할 때 오르는 기준, 입력이 없으면 입력 안내입니다. 기준값은 판정과 같은 공식 기준만 씁니다.
- **추천:** 조건을 모두 충족한 상품만 추천합니다(확인 필요는 추천하지 않음). 충족한 상품이 여럿이면 **입력한 소득 구간·대출 기간의 공식 기본금리(우대 전)**가 가장 낮은 상품을 추천합니다. 같으면 신생아 특례 → 디딤돌 → 보금자리론 순입니다.
  - 금리 범위로 비교하면 신생아 특례(1.80~4.50%)와 디딤돌(2.85~4.15%)처럼 범위가 겹칠 때 정할 수 없어서 바꿨습니다(예전: 디딤돌과 보금자리론의 범위가 겹치지 않아 디딤돌).
  - 확인 필요인 상품의 기본금리가 추천 상품보다 낮을 수 있으면 "확인되면 더 낮은 금리" 안내를, 미충족 상품은 맞지 않는 조건 이름을 이유에 적습니다.
- **기본금리표 (`PolicyRates`, 2026-10-26 확인):** 디딤돌·신생아 특례는 부부합산 연소득 구간 × 만기 10/15/20/30년 표입니다. 주택도시기금 페이지가 표 칸을 채울 때 부르는 공식 주소(`/init/include/NewBabyGetInform.jsp`)의 응답을 옮겼습니다. 보금자리론은 한국주택금융공사 금리안내(2026-10-01 공시)의 t-보금자리론 만기별 고정금리입니다(아낌e는 0.1%p 낮음).
  - 연소득은 부부합산 연소득, 없으면 월 소득 × 12입니다. 대출 기간은 올림한 햇수 이상인 가장 짧은 만기 구간을 쓰고(25년 → 30년), 모르면 30년, 표보다 길면 가장 긴 만기입니다.
  - 응답의 상품마다 `baseRate`(%)와 `baseRateBasis`(소득·만기·우대 전 설명)를 넣고, 화면 추천 카드와 정책 화면에 보여 줍니다.
- **넣지 않은 상품 (2026-10-26 확인):** 기본형 적격대출(HF 공식 페이지에 "취급 잠정 중단"), 청년 주택드림 디딤돌(청약 당첨자 전용, 입력 2개 추가 필요), 주택연금(구입 자금이 아님).
- **판정하지 않는 조건:** 면적, 자산, 신용, 세대주, 규제지역은 판정하지 않고 `additionalChecks`로 안내합니다.
- **기준이 바뀌면:** `PolicyService` 상수, 이 표, `PolicyServiceTest`를 함께 고칩니다.
- **확인 필요:** 보금자리론의 "다자녀 가구"는 상품안내 페이지에 인원 정의가 없습니다. 금리안내 페이지 우대금리 표(다자녀가구 2자녀 / 3자녀 이상)를 근거로 **자녀 2명 이상**으로 처리했습니다 (공식 정의 아님, 고객센터 1688-8114 확인 필요). 소득 기준(1억 원)과 한도(4억 원)에 영향을 줍니다.
