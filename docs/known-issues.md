# 알려진 문제 목록

HomeFin Mate를 처음부터 다시 구현하면서 찾은 문제입니다.
기존 동작을 먼저 그대로 재현한 뒤, 테스트, 실제 요청, 코드 확인으로 문제를 기록하고 고칩니다.

- **확인**: 문제를 어떻게 확인했는지 (테스트 / 실서버 요청 / 실측 / 코드)
- **상태**: `미해결` · `해결` (재구현하면서 처음부터 반영) · `우회` (임시로 피해 둠)
- **수정 PR**: Phase 13에서 고친 PR 번호를 기입

---

## 진행 순서

1. **성능: 측정 → 개선 → 다시 측정** ([성능 측정 계획과 결과](performance.md))
   - S1 외부 시스템 장애 시 응답 시간: #35, #36, #42
   - S2 외부 호출 중 DB 커넥션 점유와 저장 불일치: #71, #5
   - S3 데이터가 쌓였을 때 조회 속도: #45, #51 (인덱스 없음)
2. 아래 "우선 처리" J1~J4
3. 보안, 나머지 순서
